TypeScript definition files for Olive.MvcJs peer libraries and global augmentations.

Primary definitions live in `index.d.ts`. Legacy per-library folders under `jquery/`, `bootstrap/`, etc. are retained for reference but are superseded by `index.d.ts` at compile time.

For maintained type packages during development, see devDependencies in package.json.

Host applications should follow `UPGRADE.md` for peer library versions.
